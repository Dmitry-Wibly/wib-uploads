# wib uploads

Находит рекламу в роликах YouTube и сохраняет нужные куски в mp4. Ещё скачивает видео из соцсетей, сохраняет посты Telegram картинками и ищет выпуски блогеров с нужным брендом. Всё работает на твоём Mac, ничего не отправляется на чужие серверы.

Страница проекта: https://wibuploads.online

## Что умеет

| Режим | Что делает |
|---|---|
| **Найти рекламу** | Читает описание и субтитры ролика YouTube, показывает рекламные куски с таймкодами. Ты отмечаешь нужные, а программа режет их в mp4 |
| **Выгрузить рекламу** | Скачивает видео из VK, TikTok, Instagram\* и Rutube целиком, в папку с именем блогера |
| **Выгрузить посты** | Сохраняет пост Telegram картинкой JPG. Если пост удалили, ищет его копию в веб-архиве |
| **Поиск интеграций** | Ты вписываешь блогеров и бренды, программа даёт ссылки на выпуски и объясняет, почему они подошли |

## Установка за 5 минут

Нужен Mac. На Windows и Linux пока не работает.

### Способ 1. Двойным кликом (проще всего)

1. Скачай проект: на странице репозитория нажми **Code → Download ZIP** и распакуй архив.
2. Дважды кликни файл **«Установить.command»**. Если Mac пишет, что не может проверить разработчика, нажми по файлу правой кнопкой и выбери «Открыть».
3. Отвечай на вопросы в окне. Обычно нужно только разрешить поставить то, чего не хватает.
4. Откроется страница http://wibuploads.localhost:8788. Если не открылась, вставь этот адрес в браузер сам.

Установщик проверит Python, поставит `yt-dlp` и `ffmpeg` (через Homebrew) и включит автозапуск. Посты Telegram он ставит только если ты согласишься: для них скачивается ещё около 200 МБ.

### Способ 2. Из терминала

```
git clone https://github.com/Dmitry-Wibly/wib-uploads.git ~/Desktop/ytads
cd ~/Desktop/ytads && bash install.sh
```

## Первый запуск

На странице откроется вкладка **«Старт»**. Это проверка, что готово, а что нет:

- **Программы для скачивания.** Зелёное значит, что `yt-dlp` и `ffmpeg` на месте.
- **Связь с YouTube.** Кнопка проверит, открывается ли YouTube. Если нет, смотри раздел про VPN ниже.
- **Тестовое скачивание.** Проверяет, что программа видит ролик YouTube.
- **Нейросеть.** С ней реклама находится точнее. Подойдёт Claude Code или ключ OpenAI (вставляется прямо на странице). Без нейросети программа ищет по словам из описания, это работает, но ошибок больше.
- **Куки.** Нужны, если YouTube просит доказать, что ты не бот. Пошаговая инструкция есть во вкладке «Куки».
- **Ключ YouTube API.** Нужен только для режима «Поиск интеграций». Инструкция там же.

Жёлтые пункты можно пропустить: тогда не заработают только связанные с ними функции. Все ключи хранятся на твоём компьютере в папке `.secrets` и в репозиторий не попадают.

## VPN

| Как работает твой VPN | Что делать |
|---|---|
| Приложение на весь компьютер (режим TUN) | Ничего. Поле «Прокси» оставь пустым |
| VPN как прокси (v2ray, Clash, Hiddify) | В «Настройках» впиши адрес `socks5://127.0.0.1:ПОРТ`. Порт смотри в самом приложении |
| Расширение для браузера | Не подойдёт: на программу оно не действует. Нужно приложение |

С VPN YouTube чаще просит войти в аккаунт, потому что адреса у VPN общие. Если видишь ошибку «not a bot», добавь куки. Лучше завести для этого отдельный аккаунт: иногда YouTube ограничивает аккаунт, который скачивает программами. VK и Rutube программа качает в обход прокси. Если VPN включён на весь компьютер и они не открываются, выключи его на время.

## Не получается?

| Что видишь | Что делать |
|---|---|
| «Не нашёл yt-dlp или ffmpeg» | Запусти «Установить.command» ещё раз или выполни `brew install yt-dlp ffmpeg` |
| Mac не открывает «Установить.command» | Правый клик по файлу, «Открыть», и подтверди. Или в терминале: `bash install.sh` |
| «not a bot» или просит войти | Добавь куки во вкладке «Куки» |
| YouTube не открывается | Включи VPN на весь компьютер или впиши прокси, см. раздел про VPN |
| Страница не открывается | Выполни `sh autostart`, подожди несколько секунд. Лог лежит в `~/Library/Logs/ytads.log` |

Если не помогло, попроси помощи у ChatGPT. Скопируй этот текст и вставь в чат:

```
Помоги мне установить программу wib uploads на мой Mac. Описание и шаги здесь: https://github.com/Dmitry-Wibly/wib-uploads (прочитай README). Если не можешь открыть ссылку, попроси меня вставить текст README.

Веди меня по одному шагу и жди ответа, прежде чем давать следующий. Говори простыми словами. Сначала спроси, какая у меня версия macOS, есть ли Homebrew и как работает мой VPN: приложение на весь компьютер, прокси или расширение браузера. Если пришлю текст ошибки, объясни причину и скажи, что делать.

```

Этот же текст есть на странице во вкладке «Старт».

## Как удалить

```

```

Потом удали папку проекта. Скачанные файлы лежат отдельно, на рабочем столе, их программа не трогает.

# Для тех, кто хочет разобраться

## Страница

Адрес: **http://wibuploads.localhost:8788**. Страница открывается только на этом Mac, её отдаёт локальный сервер. Браузеры сами ведут любой адрес `*.localhost` на твой компьютер, настраивать ничего не нужно.

Сервис запускается сам при входе в систему. Включить или обновить: `sh autostart`, выключить: `sh autostart off`. Лог лежит в `~/Library/Logs/ytads.log`. После `git pull` выполни `sh autostart` ещё раз. Сервер принимает запросы только со своей страницы.

Вверху четыре режима. Под строкой поиска три вкладки: **«Старт»** (проверка, что готово), **«Настройки»** и **«Куки»**. В режимах «Выгрузить посты» и «Поиск интеграций» остаётся только «Старт».

## Выгрузить рекламу: видео из соцсетей

Режим для VK, TikTok, Instagram\* и Rutube. Вставь ссылки, по одной на строку, и нажми «Скачать». Видео скачивается целиком, горизонтальное или вертикальное, в папку `~/Desktop/Видео из соцсетей/<имя блогера>/`. Если нужна своя папка, впиши её название в поле под строкой поиска.

В результатах видно площадку, блогера, ориентацию, разрешение и длину. Всё это записывается в `videos.csv` в той же папке. Качество выбирается во вкладке «Настройки».

VK, TikTok и Rutube качаются без входа в аккаунт, и прокси для VK и Rutube программа не использует. Instagram пускает только вошедших в аккаунт: добавь куки instagram.com во вкладке «Куки» тем же расширением. Они дописываются в `cookies.txt` рядом с куками YouTube. В терминале то же самое делает `ytads get ССЫЛКИ`, а `-f "Папка"` задаёт своё название папки.

## Выгрузить посты: Telegram в JPG

Вставь ссылки на посты вида `https://t.me/канал/123` и нажми «Сохранить». Каждый пост сохраняется картинкой, как он выглядит в Telegram: текст, фото, реакции, просмотры и дата. Файлы лежат в `~/Desktop/Посты Telegram/<канал>/`, список постов в `posts.csv`. Свою папку можно задать в поле под строкой поиска.

Если пост удалили, программа ищет его копию в веб-архиве (web.archive.org): страницы каналов `t.me/s/канал` туда часто попадают. Найденная копия помечена «архив ГГГГ-ММ-ДД». Если копии нет, программа скажет об этом прямо. Поиск в архиве занимает до минуты на пост. Закрытые каналы (ссылки `t.me/c/…`) не поддерживаются.

Снимки делает Chromium через Playwright. Установщик ставит его по твоему согласию в `~/.wibuploads/venv`. Вручную: `pip3 install playwright && python3 -m playwright install chromium`. В терминале: `ytads tg ССЫЛКИ`.

## Поиск интеграций

Вписываешь блогеров, по одному на строку: имя, @handle, ссылку на канал или на любой его ролик. В поле «Что искать в описании» пишешь слова через запятую, например `Т-Банк, Хоккейный вклад`. Если кампания началась в известный день, укажи его в поле «Выпуски с». Тогда проверяются только свежие ролики.

Описания читаются через YouTube Data API пачками по 50 роликов. YouTube это не нагружает, блокировок нет. В ответе по каждому выпуску есть строка «Блогер | ролик», ссылка и идентификация: какие слова нашлись, ссылка на продукт, промокод, erid. Слова с разными падежами и написаниями («Т-Банк», «ТБанк», «Тинькофф») находятся вместе. Если слово просто упомянуто и признаков рекламы рядом нет, ролик помечен «только упоминание» и стоит внизу. Таблицу можно скопировать в Google Таблицы по столбцам, она же пишется в `~/Desktop/Поиск интеграций/*.csv`. Кнопка «Выдернуть рекламу из найденных» переносит ссылки в режим «Найти рекламу».

Ключ API добавляется во вкладке «Старт» или кладётся в `.secrets/youtube_api_key.txt` (папка 700, файл 600, в git не попадает), либо в переменную `YTADS_YT_KEY`. Лимит бесплатный: 10 000 единиц в день. Канал на 1000 роликов стоит около 20 единиц, а поиск канала по имени 100. Поэтому надёжнее давать @handle или ссылку.

## Терминал

То же самое делается из терминала. Команда `ytads` доступна из любой папки через ссылку в `~/.local/bin`.

```
ytads https://youtu.be/AAA https://youtu.be/BBB   # найти рекламу и сохранить её в mp4
ytads                                             # то же для ссылок из буфера обмена
ytads -n https://youtu.be/AAA                     # только показать отрезки
ytads -a https://youtu.be/AAA                     # сохранить все отрезки, не только рекламу
ytads -q 720 …                                    # качество, по умолчанию 1080
ytads -k "вкусвилл,тинькофф" …                    # свои подсказки: слова, по которым искать рекламу
ytads get ССЫЛКИ [-f "Папка"]                     # видео из соцсетей целиком
ytads tg ССЫЛКИ [-f "Папка"]                      # посты Telegram в JPG
ytads web                                         # запустить страницу без автозапуска
ytads cookies                                     # сохранить куки из буфера обмена
```

Команда печатает найденные отрезки по каждому ролику и сразу режет те, что похожи на рекламу.

### Куки из терминала

Если куки протухли, `ytads` останавливается и подсказывает, что делать:

1. Открой youtube.com в браузере, где ты вошёл в аккаунт.
2. В расширении «Get cookies.txt LOCALLY» нажми **Export**. Куки попадут в буфер обмена.
3. Вернись в терминал и нажми Enter. Куки заберутся из буфера, работа продолжится.

Сохранить куки отдельно можно командой `ytads cookies` сразу после Export.

`ytads web` запускает страницу на http://wibuploads.localhost:8788. Двойной клик по `ytads.command` делает то же самое. Остановить: `Ctrl+C`.

## Как ищется реклама

1. Вставляешь ссылки на ролики YouTube, по одной на строку, и нажимаешь «Найти».
2. Границы кусков собираются из трёх источников:
   - **главы** ролика, из них же берётся подпись;
   - **таймкоды в описании**: отрезок заканчивается там, где начинается следующий;
   - **SponsorBlock**: база, где зрители сами размечают рекламу. По умолчанию включены «Реклама» и «Самореклама автора», остальное отмечается в «Настройках».
3. Куски из разных источников с похожими границами сливаются в один. Границы берутся от SponsorBlock как более точные, а подпись от главы или описания как более понятная. Короткая реклама внутри длинной главы остаётся отдельной строкой.
4. Рекламные куски отмечаются сразу по словам `реклам`, `спонсор`, `промокод`, `партнёр`, `интеграц`, `скидк`, `sponsor`, `promo` и другим. Фразы вроде «это не реклама» не считаются. Свои слова добавляются в «Настройках», в поле «Свои подсказки».
5. **Нейросеть.** Если подключён Claude Code (команда `claude`) или ключ OpenAI, программа отдаёт ей описание и автосубтитры, а нейросеть возвращает рекламные вставки с брендом и границами. Выбор лежит в «Настройках», в поле «Нейросеть»: подойдёт любая подключённая, либо только Claude, либо только ChatGPT, либо без нейросети. Если реклама уже есть в SponsorBlock или в главах, остаются их границы, а нейросеть дописывает бренд.
   - Точность измерена только для Claude: на 13 роликах с известной рекламой он нашёл 36 вставок из 38, и в 33 случаях границы совпали с точностью до 10 секунд. На ролик уходит 20–40 секунд. Для ChatGPT точность на этих роликах ещё не измерена.
   - Модель Claude задаётся переменной `YTADS_MODEL` (по умолчанию `sonnet`). Для ChatGPT модель выбирается из доступных по ключу, её можно задать через `YTADS_OPENAI_MODEL`. Отключить нейросеть совсем: `YTADS_AI=off`. Остальные значения: `auto`, `claude`, `openai`.
   - **Без нейросети по описанию.** Программа читает маркировку («Реклама. АО «ТБанк» … erid», «WB Ресейл … Erid», промокод со ссылкой) и для каждого рекламодателя ищет его место в субтитрах по словам его же рекламного блока и ссылки. Бренд в субтитрах часто искажён («VBALE» вместо WB), а слоган совпадает дословно: «продавай без комиссии, покупай безопасно». Края вставки ставятся по ближайшей паузе или отбивке «[музыка]». Найденное подписано названием бренда, оно попадает в имя файла и в колонку `бренд` в `ads.csv`. Если рекламодатель есть в описании, а места в ролике не нашлось, программа говорит об этом отдельно.
   - **Без маркировки** программа ищет в субтитрах места, где рядом звучат бренд и призыв: «ссылка в описании», промокод, QR-код, «ненадолго прервёмся», «возвращаемся к выпуску». Бренды берутся из маркировки, из «Своих подсказок» и из названий, которые звучат кучно в одном месте ролика. Такие строки помечены источником `субтитры`, границы у них примерные, поэтому рядом есть значок ▶: по нему ролик открывается с этого места, и можно проверить. В «Настройках» поле «Субтитры» принимает значения «Если нет таймкодов» (по умолчанию), «Всегда» и «Не читать». В терминале то же самое через `-t auto|always|off`.
6. Любое время можно поправить руками. Лишнее снимается, нужное отмечается, показываются все куски, не только рекламные.
7. Кнопка **«Сохранить в mp4»** кладёт файлы в `~/Desktop/Рекламные фрагменты/<Канал>/` и дописывает строку в `ads.csv`.

## Что получается

Файл: `~/Desktop/Рекламные фрагменты/<Канал>/0-04-12 - <Название ролика> - <подпись>.mp4`. Метка `ч-мм-сс` в начале имени нужна для сортировки: файлы идут в том порядке, в каком реклама появляется в ролике.

Список `~/Desktop/Рекламные фрагменты/ads.csv` открывается в Numbers и Excel без настроек (разделитель точка с запятой, кодировка с BOM). В нём дата, канал, ролик, ссылка, id, начало, конец, длина в секундах, подпись, источники, путь к файлу и бренд. Новые строки дописываются, прошлые сборы не теряются.

Скачивается только нужный отрезок (`--download-sections`), а не весь ролик. Если YouTube не отдаёт отрезок, программа берёт ролик целиком в `~/Desktop/Рекламные фрагменты/.source` (кэш используется повторно) и режет через ffmpeg.

## Доступ к YouTube

YouTube иногда отвечает `Sign in to confirm you're not a bot`. Тогда нужны куки аккаунта, в котором ты вошёл. Выбор лежит в «Настройках», в поле «Куки»:

- **Файл из вкладки «Куки»**: самый надёжный путь. Расширение «Get cookies.txt LOCALLY» экспортирует куки для youtube.com, ты вставляешь их во вкладку «Куки», а программа сама сохраняет файл.
- **Взять из Chrome**: работает, если вход на YouTube выполнен именно в Google Chrome.
- **Взять из Arc**: выбрать можно, но yt-dlp расшифровывает куки Arc ключом Chrome, и больше половины куки не читается. Для Arc лучше путь через файл.
- Остальные браузеры (Brave, Edge, Firefox, Safari) выбираются так же, их работа зависит от системы.

Прокси подставляется само по типовым локальным портам, например `socks5://127.0.0.1:10808`. Если VPN включён для всего компьютера, поле оставь пустым. Провайдер PO-токена из `~/.local/share/bgutil-pot` (по желанию) подключается сам: без него отказ YouTube приходит через 29 секунд вместо 2.

## Устройство

| Файл | Что делает |
|---|---|
| `server.py` | Локальный сервер: разметка рекламы, скачивание, Telegram, поиск интеграций, проверка готовности |
| `index.html` | Страница, один файл без сборки |
| `tgshot.py` | Снимки постов Telegram через Playwright и поиск копий в веб-архиве |
| `cli.py`, `ytads` | Те же функции в терминале |
| `install.sh`, `Установить.command` | Установка в один шаг |
| `autostart` | Запуск сервиса при входе в систему (launchd) |
| `.secrets/` | Ключи API, только на твоём компьютере |

Страница общается с сервером через `/api/scan`, `/api/grab`, `/api/social`, `/api/telegram`, `/api/find` (запуск задач), `/api/job/<id>` (ход работы), `/api/doctor`, `/api/netcheck`, `/api/test`, `/api/secret` (вкладка «Старт»), `/api/cookies`, `/api/env`.
