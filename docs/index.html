Рекламные интеграции из роликов одной кнопкой

wibuploads находит рекламу в видео на YouTube и сохраняет нужные куски в mp4. Ещё умеет скачивать видео из соцсетей, сохранять посты Telegram картинками и искать выпуски блогеров с нужным брендом. Всё работает на твоём компьютере.

Скачать

Четыре режима

Найти рекламу

Читает описание и субтитры, показывает рекламные куски с таймкодами. Ты отмечаешь нужные, а сервис режет их в mp4.

Выгрузить рекламу

Скачивает видео из VK, TikTok, Instagram* и Rutube целиком, горизонтальные и вертикальные, в папку с именем блогера.

Выгрузить посты

Сохраняет пост Telegram картинкой JPG. Если пост удалили, ищет его копию в веб-архиве.

Поиск интеграций

Вписываешь блогеров и бренды, получаешь ссылки на выпуски и объяснение, почему они подошли: ссылка, промокод, erid.

Как начать

  1. Нажми «Скачать» выше и распакуй архив. Нужен Mac.
  2. Дважды кликни файл «Установить.command». Если Mac не пускает, нажми по файлу правой кнопкой и выбери «Открыть». Установщик сам поставит всё нужное и спросит только то, что без тебя не решить.
  3. Откроется страница программы. Вкладка «Старт» покажет, что уже работает, а что осталось настроить, и проведёт дальше.

Не получается? В README лежит готовый текст для ChatGPT: он проведёт по шагам и поможет разобраться с ошибкой.

Что полезно знать

  • Всё остаётся у тебя. Куки, ключи и скачанные файлы хранятся только на твоём компьютере.
  • Если YouTube просит войти, добавь куки во вкладке «Куки». Там есть пошаговая инструкция.
  • VPN. Если он включён для всего компьютера, прокси не нужен. Если VPN работает как прокси, впиши его адрес в настройках.
  • Нейросеть по желанию. С Claude Code или ключом OpenAI реклама находится точнее. Без них сервис ищет по описанию и словам.
